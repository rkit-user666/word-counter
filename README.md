## Название плагина
**Word Counter (Lab 3)**

## Описание и возможности
Плагин разработан для среды Visual Studio Code и предназначен для быстрого анализа метрик выделенного текста. Он помогает разработчику прямо внутри IDE оценивать объемы кода или текстовых комментариев в файлах проекта.

### Основной функционал и возможности:
1. **Интеграция в Command Palette:** Команда `Count Words & Characters (Lab 3)` доступна по нажатию `Ctrl + Shift + P`.
2. **Интеграция в контекстное меню:** Пункт для подсчета отображается при правом клике мыши на выделенном фрагменте текста.
3. **Расчёт метрик текста:**
   * Общее количество символов (включая пробелы).
   * Количество чистых символов (без пробелов и знаков переноса строк).
   * Точное количество слов в выделении.
   * Количество строк.
4. **Модальное окно:** Результаты выводятся в виде аккуратного центрального диалогового окна.

## Инструкция по запуску
1. Откройте папку проекта в VS Code.
2. Нажмите клавишу `F5` для запуска плагина в режиме отладки (откроется новое тестовое окно).
3. В открывшемся окне выделите любой текст в любом файле, нажмите `Ctrl + Shift + P` и выберите команду `Count Words & Characters (Lab 3)`.
